## 🎯 核心功能实现

### 1. Parser Agent

**功能**: 
- 使用 LLM (GPT-4o-mini) 解析自然语言需求
- 提取结构化设计意图（时钟、复位、接口、约束）
- 支持中英文输入

**关键特性**:
- 智能识别接口协议（AXI、APB、UART、SPI等）
- 自动提取频率、数据位宽等约束
- 带 fallback 机制的正则表达式解析

**输出格式**:
```python
{
  "intent": {
    "summary": str,
    "target_language": "verilog",
    "clock": "clk",
    "reset": "rst_n",
    "interfaces": ["axi-lite"]
  },
  "constraints": {
    "hard": [{name, value, priority}],
    "soft": [{name, value, priority}]
  }
}
```

### 2. Architect Agent with RAG

**功能**:
- 基于设计意图生成模块层次树
- 使用 RAG 检索相似设计模式
- 定义端口规范与接口

**RAG 集成**:
- **向量数据库**: ChromaDB
- **Embedding 模型**: OpenAI text-embedding-3-small
- **检索策略**: 混合检索（语义 + 关键词过滤）
- **知识来源**: HDL 设计模式、协议规范、最佳实践

**输出格式**:
```python
{
  "version": 1,
  "hierarchy": {
    "top": {
      "name": str,
      "type": "top",
      "children": [str],
      "ports": {...}
    },
    "modules": [...]
  },
  "interfaces": [...]
}
```

### 3. PPA Estimator

**功能**:
- 基于规则的面积、功耗、时序评估
- 可行性评级（high/medium/low）
- 警告信息生成

**评估方法**:
- **面积**: 基于模块类型复杂度因子
- **功耗**: 动态功耗（翻转活动）+ 静态功耗（漏电）
- **时序**: 逻辑级数估算 + 门延迟

**输出格式**:
```python
{
  "area": {
    "total_gates": int,
    "breakdown": {...}
  },
  "power": {
    "total_mw": float,
    "breakdown": {...}
  },
  "timing": {
    "max_freq_mhz": float,
    "critical_path": {...}
  },
  "feasibility": "high|medium|low",
  "warnings": [...]
}
```

## 🔗 工作流架构

```
用户需求 (自然语言)
    ↓
Parser Agent (LLM解析)
    ↓
State: {intent, constraints, metadata}
    ↓
Architect Agent (RAG增强)
    ↓
State: {architecture, versions}
    ↓
PPA Estimator (规则引擎)
    ↓
State: {ppa, feasibility, warnings}
    ↓
[Manager Agent 接管] (未实现)
```

## 📊 State Schema 设计

完整的 `AGVSState` TypedDict 包含 12 个字段，支持整个工作流：

- **Pre-processing**: `intent`, `constraints`, `metadata`
- **Architecture**: `architecture`, `ppa`
- **Verification**: `coverage`, `errors`
- **Control**: `retry_count`, `loop_budget`, `versions`
- **Generation**: `modules`, `tests`

## 🚀 使用示例

### 方式 1: 使用工作流函数

```python
from app.workflow import run_pre_manager_workflow

requirement = "设计一个200MHz的AXI寄存器文件"
result = run_pre_manager_workflow(requirement)

print(f"架构: {result['architecture']}")
print(f"PPA: {result['ppa']}")
```

### 方式 2: 独立使用Agent

```python
from app.pre_agent.parser_agent import ParserAgent
from app.manage_agent import ArchitectAgent, PPAEstimator

# 解析需求
parser = ParserAgent()
parsed = parser.parse("设计一个AXI寄存器文件")

# 生成架构
architect = ArchitectAgent(use_rag=True)
arch = architect.design(
    parsed.intent.model_dump(),
    parsed.constraints.model_dump()
)

# PPA 评估
estimator = PPAEstimator()
ppa = estimator.estimate(arch, parsed.constraints.model_dump())
```
